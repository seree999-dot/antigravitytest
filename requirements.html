2. System Requirements

ความต้องการด้านฟังก์ชันและด้านประสิทธิภาพของระบบ

Functional Requirements (FR)

FR-1
Authentication System

ระบบต้องอนุญาตให้ผู้ใช้สมัครสมาชิก เข้าสู่ระบบ และจัดการโปรไฟล์ส่วนตัวได้

FR-2
AI Code Generation

มีช่องให้ผู้ใช้พิมพ์ Prompt และระบบต้องส่งข้อมูลไปประมวลผลกับ LLM API เพื่อสร้างโค้ด UI

FR-3
Live Code Preview

เรนเดอร์โค้ดที่สร้างขึ้นให้แสดงผลเป็น UI บนหน้าเว็บได้ทันที โดยสามารถสลับดู Code / Preview ได้

FR-4
Snippet Management

ผู้ใช้สามารถกดบันทึกโค้ดถูกใจเก็บไว้ใน My Library ส่วนตัว และสามารถลบทิ้งได้

FR-5
Community & Social Features

ผู้ใช้สามารถเผยแพร่โค้ดไปยัง Community Feed ได้ และสามารถกดค้นหา กดไลก์ผลงานได้

Non-Functional Requirements (NFR)

⚡ NFR-1: Performance

ระยะเวลาตั้งแต่ผู้ใช้กด Generate จนถึงเวลาที่แสดงผลโค้ด ต้องใช้เวลาไม่เกิน 10 วินาที

🔒 NFR-2: Security

Live Preview ต้องทำงานใน Sandboxed Iframe อย่างเคร่งครัด เพื่อป้องกันการโจมตีแบบ XSS (Cross-Site Scripting)

📱 NFR-3: Usability

เว็บไซต์ต้องแสดงผลแบบ Responsive รองรับการใช้งานทั้งบน Desktop, Tablet และ Mobile อย่างลื่นไหล

🛡️ NFR-4: Reliability

ต้องมี Graceful Degradation จัดการ Error อย่างชัดเจนในกรณีที่ LLM API ล่มหรือตอบสนองช้า
