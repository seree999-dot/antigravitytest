4. Business Rules, Risks & Traceability

กฎทางธุรกิจ ความเสี่ยงของโปรเจกต์ และตารางสอบกลับความต้องการ

Business Rules

  • BR-1
    Quota Limit (โควตาการใช้งาน)

    ผู้ใช้งานฟรีสามารถใช้ AI สร้างโค้ดได้สูงสุด 20 ครั้งต่อวัน เพื่อควบคุมต้นทุนค่า LLM API หากเกินกำหนดระบบจะบล็อกจนกว่าจะถึงวันใหม่

  • BR-2
    Content Moderation

    ห้ามไม่ให้มีการ Generate เนื้อหาที่ผิดกฎหมาย หรือลามกอนาจาร โดยระบบจะตรวจสอบคำหยาบก่อนส่ง Prompt ให้ AI เสมอ

  • BR-3
    Public by Default

    Snippet ที่ถูกสร้างในโหมดฟรี จะถูกตั้งค่าเป็น Public และนำไปแสดงบน Community Feed โดยอัตโนมัติ (ยกเว้นผู้ใช้เข้าไปลบทิ้งเอง)

Risk Management

💸 ต้นทุน API พุ่งสูง (Cost Overrun)
Impact: สูง Prob: สูง

Mitigation: กำหนด Rate Limit รายวันเคร่งครัด ใช้ Caching สำหรับ Prompt ที่ซ้ำกัน และเลือกใช้ Model ที่ราคาถูกสำหรับแผนฟรี

🤖 Prompt Injection & Hallucination
Impact: สูง Prob: ปานกลาง

Mitigation: วางโครงสร้าง System Prompt ให้รัดกุมที่สุด จำกัดขอบเขตให้ออกแบบเฉพาะ UI เท่านั้น หากหลุดกรอบให้ตอบปฏิเสธ

🔓 ความปลอดภัยของ Live Preview (XSS)
Impact: ร้ายแรงที่สุด Prob: ต่ำ

Mitigation: โค้ด Preview ต้องถูกจำกัดสิทธิ์ด้วย <iframe sandbox="allow-scripts"> ป้องกันไม่ให้เข้าถึง Cookie หรือ LocalStorage ของเว็บหลัก
