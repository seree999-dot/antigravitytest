3. User Stories & Acceptance Criteria

เรื่องราวผู้ใช้งานและเกณฑ์การยอมรับการทำงานของฟีเจอร์

US-1: Generate Code from Prompt

ในฐานะ ผู้ใช้งานทั่วไป
ฉันต้องการ พิมพ์คำอธิบาย UI ที่ฉันคิดไว้ลงในช่อง Prompt
เพื่อให้ AI เขียนโค้ด UI นั้นออกมาให้ฉันโดยอัตโนมัติ

Acceptance Criteria (เกณฑ์การยอมรับ)

  • เมื่อพิมพ์ข้อความและกด "Generate" ระบบต้องแสดง Loading State ทันที
  • ถ้าผู้ใช้กรอก Prompt ว่างเปล่า ระบบต้อง Disable ปุ่ม Generate ไว้แต่แรก
  • หากระบบ API ขัดข้อง ต้องแสดงข้อความเตือนให้ลองใหม่
US-2: Live Code Preview

ในฐานะ ผู้ใช้งานทั่วไป
ฉันต้องการ เห็น Preview ของโค้ดที่ AI สร้างขึ้นทันทีบนหน้าจอ
เพื่อให้ ฉันสามารถตรวจสอบผลลัพธ์ว่าตรงกับที่ต้องการหรือไม่โดยไม่ต้องนำไปรันเอง

Acceptance Criteria

  • ถ้า API ตอบกลับสำเร็จ โค้ดจะต้องถูกเรนเดอร์ลงในแท็บ "Preview" ทันที
  • มีปุ่มสำหรับสลับดูโค้ดดิบ (Source Code) ในแท็บ "Code"
  • การแสดงผล Preview ต้องอยู่ใน iframe sandbox อย่างปลอดภัย
US-3: Save Snippet to Library

ในฐานะ ผู้ใช้ที่เข้าสู่ระบบแล้ว
ฉันต้องการ บันทึก Snippet ที่ฉันสร้างเก็บไว้
เพื่อให้ ฉันสามารถกลับมาดู นำไปใช้งานต่อ หรือแก้ไขในอนาคตได้

Acceptance Criteria

  • ปุ่ม "Save" จะใช้งานได้ก็ต่อเมื่อผู้ใช้ล็อกอิน (ถ้ายังไม่ล็อกอิน ให้แสดง Modal ชวนล็อกอินเมื่อกดคลิก)
  • หลังจากบันทึกสำเร็จ ข้อมูลจะต้องไปปรากฏในหน้า "My Library" ของผู้ใช้ทันที
US-4: Community Discovery

ในฐานะ ผู้ใช้งานทั่วไป
ฉันต้องการ เข้าไปดูและค้นหาผลงานในหน้า Community Feed
เพื่อให้ ฉันได้แรงบันดาลใจและสามารถคัดลอก (Fork) โค้ดของคนอื่นมาปรับแก้ต่อได้

Acceptance Criteria

  • หน้า Feed จะต้องแสดงการ์ดผลงานเรียงตามความใหม่หรือความนิยม (Trending)
  • มีช่อง Search สำหรับพิมพ์ค้นหาผลงานด้วย Keyword
  • มีปุ่ม "Fork" บนผลงานคนอื่น เพื่อนำโค้ดนั้นมาเปิดใน Editor ส่วนตัวทันที
