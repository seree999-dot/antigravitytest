1. Overview & Scope (ภาพรวมและขอบเขต)

แพลตฟอร์มสำหรับสร้างและแชร์ UI/Code Components จากคำอธิบายด้วย AI

Problem (ปัญหาที่ต้องการแก้ไข)

1. กระบวนการเขียนโค้ดที่ซ้ำซ้อน: นักพัฒนาและนักออกแบบมักเสียเวลาไปกับการเขียนโค้ด UI Components หรือโค้ดพื้นฐาน (Boilerplate) เดิมๆ ซ้ำๆ ทำให้การพัฒนาโปรเจกต์ล่าช้า

2. ช่องว่างระหว่างไอเดียกับโค้ด: ผู้ใช้มีภาพในหัวหรือ "Vibe" ที่ต้องการ แต่ขาดเครื่องมือที่สามารถแปลงคำอธิบายแบบภาษาธรรมชาติ (Natural Language) ให้กลายเป็นโค้ดที่พร้อมใช้งานได้ทันที

3. ขาดแหล่งรวมแรงบันดาลใจ: ปัจจุบันยังไม่มีคอมมูนิตี้ศูนย์กลางที่เน้นการแชร์และค้นหา Code Snippets ที่สร้างจาก AI โดยเฉพาะ ที่นักพัฒนาสามารถนำไปต่อยอด (Remix) หรือ Fork ไปใช้งานต่อได้ง่าย

Scope (ขอบเขตของระบบ)

✅ In-Scope (สิ่งที่ทำ)

  • ระบบสมัครสมาชิกและเข้าสู่ระบบ (Email, GitHub)
  • ช่องพิมพ์คำสั่ง (Prompt) สำหรับให้ AI สร้างโค้ด (HTML, React, Vue)
  • ระบบ Live Preview แสดงผลแบบเรียลไทม์ผ่าน Sandbox
  • ระบบจัดการ Snippet ส่วนตัว (บันทึก, แก้ไข, ลบ)
  • Community Feed (ค้นหา, กดไลก์, Share, Fork โค้ด)

❌ Out-of-Scope (สิ่งที่ยังไม่ทำ)

  • การสร้าง Backend Logic, Database Schema หรือ API
  • ระบบ IDE Integration (VS Code / Cursor Extension)
  • ระบบ Monetization (เก็บเงินผู้ใช้งาน)
  • การ Deploy โค้ดเป็นแอปพลิเคชันเต็มรูปแบบไปยัง Cloud
